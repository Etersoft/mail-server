# Логотип Почтаря / Eterpost

| Файл | Где использовать |
|---|---|
| `eterpost-mark.svg` | знак отдельно: значок сайта, интерфейс, аватары |
| `eterpost-logo.svg`, `eterpost-logo-dark.svg` | знак с надписью Eterpost для светлого и тёмного фона |
| `pochtar-logo.svg`, `pochtar-logo-dark.svg` | знак с надписью «Почтарь» для светлого и тёмного фона |
| `eterpost-avatar-512.png` | аватар организации на GitHub и GitLab (квадрат без скруглений) |

Цвета: жёлтый `#ffc72c`, тёмный `#1f2328`, надпись на тёмном фоне `#f0f3f6`.
Надпись — Noto Sans Bold, переведена в кривые, шрифт не нужен.
Знак — конверт со следом движения: письмо уходит адресатам.
